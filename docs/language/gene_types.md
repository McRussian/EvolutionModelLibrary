# Типы генов — описание для DSL

> Архитектура: [ARCHITECTURE.md](../ARCHITECTURE.md) | Стратегии скрещивания: [strategies.md](strategies.md)

Типы генов задаются в блоке `genome`. Каждый тип определяет диапазон значений,
способ мутации и стратегию скрещивания по умолчанию.

---

## Примитивные типы

### Int

```
Int(lo, hi)
```

Целочисленный ген. Значения равномерно распределены в `[lo, hi]` включительно.

| Параметр | Тип | Описание |
|---|---|---|
| `lo` | int | нижняя граница (включительно) |
| `hi` | int | верхняя граница (включительно), `hi > lo` |

**Мутация:** новое случайное число из `[lo, hi]`.  
**Скрещивание по умолчанию:** `uniform`.

```
genome Agent {
    speed: Int(0, 10)
    priority: Int(1, 5)
}
```

---

### Float

```
Float(lo, hi)
Float(lo, hi, sigma_ratio=0.1)
```

Вещественный ген. Мутация гауссова — шум с сигмой `sigma_ratio * (hi - lo)`, результат зажат в `[lo, hi]`.

| Параметр | Тип | Описание |
|---|---|---|
| `lo` | float | нижняя граница (включительно) |
| `hi` | float | верхняя граница (включительно), `hi > lo` |
| `sigma_ratio` | float | сигма мутации как доля длины диапазона (по умолчанию 0.1) |

**Мутация:** `gauss(value, sigma_ratio * (hi - lo))`, зажим в `[lo, hi]`.  
**Скрещивание по умолчанию:** `blend(alpha=0.5)`.

```
genome Particle {
    x: Float(-5.0, 5.0)
    y: Float(-5.0, 5.0, sigma_ratio=0.05)
}
```

---

### Bool

```
Bool
```

Булев ген. Значения `true` / `false`.

**Мутация:** инверсия (`flip`).  
**Скрещивание по умолчанию:** `uniform`.

---

### Categorical

```
Categorical(option1, option2, ...)
```

Категориальный ген. Значение — один из перечисленных вариантов.

| Параметр | Тип | Описание |
|---|---|---|
| `options` | список строк | допустимые варианты (минимум 2) |

**Мутация:** случайный вариант из `options`.  
**Скрещивание по умолчанию:** `uniform`.

```
genome Strategy {
    method: Categorical("greedy", "random", "heuristic")
}
```

---

### Permutation

```
Permutation(elem1, elem2, ...)
```

Перестановочный ген. Значение — перестановка всех перечисленных элементов.

| Параметр | Тип | Описание |
|---|---|---|
| `elements` | список | элементы для перестановки |

**Мутация:** случайный свап двух позиций.  
**Скрещивание по умолчанию:** OX (Order Crossover).

```
genome Route {
    path: Permutation(0, 1, 2, 3, 4)
}
```

---

### BitString

```
BitString(length)
```

Ген-битовая строка фиксированной длины.

| Параметр | Тип | Описание |
|---|---|---|
| `length` | int | количество бит, >= 1 |

**Мутация:** инверсия одного случайного бита.  
**Скрещивание по умолчанию:** `npoint(n_points=1)`.

```
genome Flags {
    mask: BitString(16)
}
```

## Составные типы

### List

```
List[InnerType](len=N)
List[InnerType](min=M, max=N)
```

Список фиксированной или переменной длины, элементы одного типа.

| Параметр | Тип | Описание |
|---|---|---|
| `InnerType` | тип гена | тип каждого элемента |
| `len` | int | фиксированная длина |
| `min`, `max` | int | диапазон длины (только для переменной длины, этап 12) |

**Скрещивание по умолчанию:** `npoint(n_points=1)`.

```
genome Vector {
    coords: List[Float(-1.0, 1.0)](len=3)
}
```

---

### Tuple

```
Tuple[Type1, Type2, ...]
```

Кортеж фиксированной длины с разными типами элементов.

**Скрещивание по умолчанию:** `elementwise`.

---

### Struct

```
Struct { field1: Type1, field2: Type2, ... }
```

Структура с именованными полями разных типов. Используется неявно при объявлении `genome`.

**Скрещивание по умолчанию:** `elementwise`.

---

### Tree

```
Tree(pset, max_depth=N)
```

Дерево выражений для символьной регрессии (Genetic Programming).

| Параметр | Тип | Описание |
|---|---|---|
| `pset` | primitives-блок | набор функций и терминалов |
| `max_depth` | int | максимальная глубина дерева |

**Скрещивание по умолчанию:** `subtree`.
