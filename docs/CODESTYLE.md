# EvoML — Стиль кода

---

## Именование

| Сущность | Стиль | Пример |
|---|---|---|
| Класс | `CamelCase` | `GeneType`, `IntGene` |
| Метод, функция | `snake_case` | `mutate`, `init_population` |
| Поле экземпляра | `_snake_case` | `_lo`, `_options` |
| Поле с name mangling | `__snake_case` | только если точно не нужен доступ из наследника |
| Публичное свойство | `snake_case` (через `@property`) | `lo`, `hi` |
| Константа модуля | `UPPER_CASE` | `DEFAULT_MUTATION_RATE` |
| Приватная константа модуля | `_UPPER_CASE` | `_DEFAULT_RNG` |
| Приватная функция модуля | `_snake_case` | `_validate_bounds` |

### Длина имён

- Минимум 2–3 символа для переменных, полей, параметров
- Однобуквенные имена допустимы только для очевидных случаев: `i`, `j` в счётчиках циклов
- Избегать сокращений, если смысл неочевиден: `population` вместо `pop`, `individual` вместо `ind`

## Классы

### Общее

- Абстрактные классы — `class Foo(ABC)`, не `metaclass=ABCMeta`
- `@abstractmethod` допускается с реализацией (вызов через `super()` из наследника)
- `@classmethod` допускается
- Ручной `__init__` везде — никаких `@dataclass`
- Валидация аргументов в конструкторе
- `__repr__` и `__str__` — вручную там, где нужен читаемый вывод
- `__eq__` — решается отдельно для каждого класса

### Поля

- Все поля объявляются в `__init__`, не снаружи
- Если поле объявляется отдельно от присваивания — указывать тип явно:

```python
result: list[int]
# ...
result = self._compute()
```

### Пример

```python
class IntGene(PrimitiveGeneType[int]):
    """Целочисленный ген с диапазоном [lo, hi].

    Args:
        lo: нижняя граница (включительно)
        hi: верхняя граница (включительно)
        rng: генератор случайных чисел

    Raises:
        InvalidBoundsError: если lo >= hi
    """

    def __init__(self, lo: int, hi: int, rng: Random = _DEFAULT_RNG) -> None:
        self._lo = lo
        self._hi = hi
        self._rng = rng

    @property
    def lo(self) -> int:
        """Нижняя граница диапазона."""
        return self._lo
```

## Типизация

- Type hints обязательны в сигнатурах всех методов и функций, включая `-> None`
- Поля класса — аннотировать в `__init__`
- Локальные переменные — только если тип неочевиден или объявление отдельно от присваивания
- Сложный тип, используемый в нескольких местах, — выносить в `type` алиас:

```python
type Fitness = float | tuple[float, ...]
type GeneValue = int | float | bool | list | dict
```

- `TypeVar` — для обобщённых классов:

```python
T = TypeVar("T")

class GeneType(ABC, Generic[T]):
    ...
```

## Случайность

- Генератор `rng: Random` передаётся явно во все методы, где нужна случайность
- По умолчанию — модульная константа `_DEFAULT_RNG = Random()`
- Это обеспечивает воспроизводимость при фиксированном seed в тестах

```python
_DEFAULT_RNG = Random()

def mutate(self, value: int, rng: Random = _DEFAULT_RNG) -> int:
    ...
```

## Исключения

- Иерархия от `EvoMLError` (база)
- `raise ... from err` допускается для цепочки исключений
- Сообщения исключений — на **английском** (с прицелом на локализацию)
- Иерархия плоская: `GeneTypeError`, `ConfigError`, `EvaluationError` — не плодить подклассы под каждый случай
- Различать ошибки одного класса по `code`, не по типу
- Коды — только через константы из соответствующего класса (`GeneTypeCodes`, `ConfigCodes`, `EvaluationCodes`), не строками напрямую
- Бросать конкретный подтип, не базовый `EvoMLError`
- При добавлении нового кода — добавить константу в соответствующий класс кодов

```python
raise GeneTypeError(GeneTypeCodes.INVALID_BOUNDS, f"lo must be < hi, got lo={lo}, hi={hi}")

try:
    ...
except ValueError as err:
    raise GeneTypeError(GeneTypeCodes.INVALID_BOUNDS, "...") from err
```

Логирование:
```python
logger.error("[%s] %s", error.code, error.message)
```

## Импорт

- Все импорты — в начале файла
- Точечный импорт (`from module import Name`) — основное правило; отступления — явно обосновываются
- Порядок групп (разделяются пустой строкой):
  1. Стандартная библиотека
  2. Сторонние пакеты
  3. Внутренние модули проекта
- Внутри группы — сортировка по алфавиту
- Длинный импорт — в скобках, каждое имя на своей строке:

```python
from evoml.core.gene_types.base import (
    CrossoverStrategy,
    GeneType,
)
```

- `__init__.py` пакета — только публичный API, который реально используется снаружи

## Структура файла

```
[импорты]

[type-алиасы и TypeVar]

[константы модуля]

[приватные функции модуля]

[классы]
```

- Две пустые строки между определениями классов и функций на уровне модуля
- Одна пустая строка между методами внутри класса

## Документация

- Стиль: **Google docstrings**
- Язык: **русский**
- Обязательны для всех публичных классов и методов
- Приватные методы — по необходимости, если логика нетривиальна

### Шаблон метода

```python
def crossover(self, a: int, b: int, rng: Random = _DEFAULT_RNG) -> tuple[int, int]:
    """Скрещивает два значения гена.

    Args:
        a: первое значение
        b: второе значение
        rng: генератор случайных чисел

    Returns:
        Пара новых значений.

    Raises:
        CrossoverError: если значения несовместимы
    """
```
