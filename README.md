# EvoML — Evolutionary Modeling Language

Высокоуровневый язык для эволюционных вычислений. Описываешь структуру генома и правила оценки — 
библиотека сама выводит операторы инициализации, мутации и скрещивания и запускает эволюцию.

---

## Зачем

Существующие библиотеки (DEAP, gplearn, PyGAD) требуют писать много boilerplate-кода:
наследовать классы, реализовывать операторы, вручную собирать цикл эволюции.
При этом для 90% задач операторы стандартные — они полностью определяются структурой генома.

EvoML переворачивает подход: **описываешь что эволюционирует, а не как**.

```
// route.evo
import data
import fitness

genome Route {
    path:  Permutation(data.cities)
    speed: Float(1.0, 10.0)
}

fitness minimize distance(g: Route) -> Float = fitness.calc_distance

evolve Route
    using GA(population=200, generations=500)
    stop_when fitness < 100.0
    observe every 50: print_stats
```

```bash
evo run route.evo
```

---

## Ключевые возможности

- **Декларативный геном** — типы генов автоматически порождают операторы
- **Многокритериальная оптимизация** — несколько `fitness` блоков дают фронт Парето
- **Переопределение операторов** — заменить дефолтный оператор для конкретного поля
- **Расширения** — подключить свои типы генов, алгоритмы, операторы одной строкой
- **Чекпоинты** — сохранять состояние и продолжать прерванный запуск
- **CLI** — один файл описания, одна команда запуска

## Структура эксперимента

```
my_experiment/
    route.evo        ← описание: геном, фитнес, конфиг запуска
    fitness.py       ← реализация фитнес-функций (обычный Python)
    data.py          ← данные: города, матрицы, наборы примитивов
```

`.evo` файл — декларативный, без логики. Вся логика — в Python-файлах рядом.

---

## CLI

```bash
evo run experiment.evo                       # запустить эксперимент
evo run experiment.evo --resume cp.json      # продолжить с чекпоинта
evo validate experiment.evo                  # проверить синтаксис без запуска
evo inspect experiment.evo                   # показать разобранную структуру
```
